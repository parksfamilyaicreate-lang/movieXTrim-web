はじめに

movieXTrim は、動画のシーンが変わる地点を自動で見つけて複数のファイルに分割したり、ブラウザで見ながら好きな区間だけを残したり削除したりできるツールです。すべてローカル（あなたのパソコン上）で動作します。

このガイドでは、画面の操作から CLI（コマンドライン）の使い方、うまくいかないときの対処法まで順番に説明します。画面右上の言語ボタンで 한국어 / English に切り替えることもできます。

動作に必要なもの: Python 3.8 以上 / Flask / ffmpeg・ffprobe（PATH に登録）。AI 機能を使う場合は Ollama と Whisper も必要です。

STEPクイックスタート

  1. python webapp/app.py を実行します。
  2. ブラウザで http://localhost:5000 を開きます。
  3. 「動画を開く」でファイルを選び「開く」を押します。アップロードが終わると動画と編集パネルが表示されます。
  4. あとは「自動分割」か「手動編集」のタブを選んで編集するだけです。

ヘッダーの 📖 使い方 を押すと、このガイドが別タブで開きます。編集画面と見比べながら確認できます。

① 自動分割（シーンチェンジ検出）

動画の色や構図が大きく変わった地点を自動で検出し、その地点でファイルを分けます。長い動画をまとめて分割したいときに便利です。

操作手順

  1. 感度（しきい値）を設定します。既定は 0.30。数値が小さいほど細かく、大きいほどはっきりした変化だけを検出します。
  2. 最小 / 最大 を設定します。「最小」は短すぎる断片を避けるための長さ、「最大」は長すぎる区間を均等に分割するための長さ（秒）です。最大は空欄で制限なしになります。
  3. 「チェンジポイントを検出」を押します。検出結果の数が表示され、下のドロップダウンに一覧が入ります。
  4. ドロップダウンから地点を選んで「選択した地点へ移動」を押すと、その時刻までシークして確認できます。
  5. 「自動分割を実行」を押すと、各区間が _part01.mp4 のような名前で保存されます。
検出結果が 0 件の場合は感度を 0.2 前後まで下げてみてください。逆に細かすぎる場合は 0.4 以上に上げます。

② 手動編集（区間を直接指定）

動画を再生しながら、残したい／消したい区間を自分で指定します。「✂ 手動編集」タブで操作します。

区間の指定方法

  1. 動画を再生し、区間の始めたい位置で一時停止して「区間開始 [I]」を押します（キーボードの I でも可）。
  2. 終わりたい位置まで移動して「区間終了 [O]」を押します（O キーでも可）。
  3. 「区間追加」を押すと、タイムラインに青いバーとして表示され、一覧に追加されます。
  4. 複数区間を追加するには 1〜3 を繰り返します。一覧の「削除」ボタンで個別に削除できます。

シーク（移動）のコツ

  • タイムラインバーをクリックすると、その割合の位置へジャンプします。
  • 「⏪ 10秒戻る」「10秒進む ⏩」で微調整できます。
  • 開始と終了を逆に指定しても自動で並べ替えられます。
  • 0.1 秒未満の区間は短すぎるため追加できません。

処理方式の選び方

方式動作向いているケース
✂ 選択区間をカット（削除）指定した区間を取り除き、残りをつなげて 1 本の動画にします。広告や不要なシーンを消したい
🔗 選択区間のみ残す指定した区間だけをつなげて 1 本の動画にします。ハイライト集を作りたい
📤 選択区間のみ抽出区間ごとに別々のファイルとして保存します。場面ごとにファイルを分けたい

方式を選んで「選択した処理を実行」を押すと確認ダイアログが出ます。処理状況は共通の進捗バーで確認できます。

③ 同時編集（2 本の動画）

2 本の動画を並べて、それぞれ別の区間を指定し、同じ操作をまとめて適用できます。「🔀 同時編集」タブで操作します。

  1. 「動画 A」「動画 B」にファイルを選び「🎬 両方開く」を押します（個別に開くこともできます）。
  2. 各動画のシークボタンで位置を合わせ、「A 開始 / A 終了」「B 開始 / B 終了」を押して区間を決めます。
  3. 「区間追加」を押すと、A と B の区間がペアで一覧に追加されます。B を指定しなかった場合は A だけが追加されます。
  4. 「🎬 同時再生」で 2 本を同時に確認できます。「⏸ 同時停止」で止めます。
  5. 処理方式（カット／残す／抽出）を選び「同一区間の処理を実行」を押すと、A → B の順に処理されます。

音声 → テキスト変換（Whisper）

日本語の音声を Whisper(base) で文字起こしします。動画を開くと「音声 → テキスト変換」カードが表示されます。

  1. 「🎙 音声 → テキスト変換」を押します。
  2. 変換が終わると、タイムスタンプ付きのテキストが表示されます。
  3. 「📋 コピー」でクリップボードにコピーできます。
初回は Whisper モデルのダウンロードに時間がかかる場合があります。長い動画ほど処理時間も増えます。

AI 機能（ベータ）

「✂ 手動編集」タブの「🤖 AI 機能を使用」チェックを入れると、AI 関連の操作が有効になります。オフのままだと通常の編集機能だけが使えます。

AI 重要区間解析

「AI重要区間を解析（ベータ）」を押すと、文字起こし結果から重要な区間の開始・終了を推定します。推定できたら「AIの提案で区間を設定」を押すと、その区間が一覧に反映されます。

AI 編集アシスタント（自然言語コマンド）

下の入力欄に日本語で指示を書くと、AI が区間を解釈して編集を実行します。

  • 5秒から15秒だけ残して
  • 3秒から10秒をカットして
  • 20秒から30秒をファイルとして抽出して
AI 機能にはローカルの Ollama（gemma4:e2b）が起動している必要があります。応答まで時間がかかることがあります。

結果の確認とダウンロード

処理が完了するとページ下部に「編集結果」が表示されます。

  • ダウンロード: ファイルを保存します。
  • プレビュー: 別ウィンドウで再生して確認します（閉じるボタンまたは Esc で閉じます）。

結果は web_results/動画ID/ フォルダにも保存されています。

CLI（コマンドライン）での使い方

ブラウザを使わずに、コマンドだけで自動分割することもできます。

# 基本: シーンチェンジを検出して分割
python scene_split.py video.mp4

# 分割計画だけ確認（実際のファイルは作らない）
python scene_split.py video.mp4 --dry-run

# 細かく検出 / 出力先を指定 / 表示言語を日本語以外に
python scene_split.py video.mp4 -t 0.2 -o parts --lang ko

# 長さの範囲を指定 / 再エンコードせず高速にカット
python scene_split.py video.mp4 --min-duration 5 --max-duration 600
python scene_split.py video.mp4 --copy
オプション既定値説明
input必須分割する動画ファイル
-o, --out<名前>_split出力フォルダ
-t, --threshold0.3検出感度（0.0〜1.0）
--min-duration1.0区間の最小長（秒）
--max-durationなし区間の最大長（秒）
--copyオフ再エンコードせずカット（高速だが位置がずれることがある）
--dry-runオフ分割計画のみ表示
--langja表示言語 ja / ko / en

ヒント・トラブルシューティング

症状対処
細かく分割されすぎる感度を 0.4, 0.5 に上げる／最小長を大きくする
チェンジが検出されない感度を 0.2 程度まで下げる
1 本の長い動画を決まった長さで分けたい最大長に 900（15分）などを指定する
動画が開けない / 長さが読めないffmpeg と ffprobe が PATH にあるか確認する
文字が化けるターミナルの文字コードを UTF-8 に設定する
AI 機能が動かないOllama が起動しているか、モデル gemma4:e2b があるか確認する

言語は画面右上のボタンでいつでも切り替えられます。選択した言語はブラウザに保存されるので、次回開いたときも同じ言語で表示されます。

시작하기 전에

movieXTrim은 동영상에서 장면이 바뀌는 지점을 자동으로 찾아 여러 파일로 나누거나, 브라우저에서 보면서 원하는 구간만 남기거나 삭제할 수 있는 도구입니다. 모든 처리는 내 컴퓨터에서 로컬로 이루어집니다.

이 설명서에서는 화면 조작부터 CLI(명령줄) 사용법, 문제가 생겼을 때의 대처법까지 순서대로 안내합니다. 오른쪽 위 언어 버튼으로 日本語 / English로도 전환할 수 있습니다.

필요한 것: Python 3.8 이상 / Flask / ffmpeg·ffprobe (PATH 등록). AI 기능을 쓰려면 Ollama와 Whisper도 필요합니다.

STEP빠른 시작

  1. python webapp/app.py 를 실행합니다.
  2. 브라우저에서 http://localhost:5000 에 접속합니다.
  3. 「동영상 열기」에서 파일을 선택하고 「열기」를 누릅니다. 업로드가 끝나면 영상과 편집 패널이 나타납니다.
  4. 「자동 분할」또는「수동 편집」탭에서 원하는 작업을 합니다.

헤더의 📖 사용설명서를 누르면 이 설명서가 새 탭에서 열립니다. 편집 화면과 나란히 보며 확인할 수 있습니다.

① 자동 분할 (장면 전환 감지)

영상의 색상이나 구도가 크게 바뀌는 지점을 자동으로 찾아 그곳에서 파일을 나눕니다. 긴 영상을 한꺼번에 분할할 때 편리합니다.

조작 순서

  1. 감지 민감도를 설정합니다. 기본값은 0.30이며, 값이 작을수록 잘게, 클수록 뚜렷한 변화만 감지합니다.
  2. 최소 / 최대 길이를 설정합니다. 「최소」는 너무 짧은 조각을 막는 길이, 「최대」는 긴 구간을 균등하게 나누는 길이(초)입니다. 최대는 비워두면 제한이 없습니다.
  3. 「전환 지점 감지」를 누릅니다. 감지된 개수가 표시되고 아래 선택 상자에 목록이 채워집니다.
  4. 목록에서 지점을 고르고 「선택 지점으로 이동」을 누르면 해당 시각으로 이동합니다.
  5. 「자동 분할 실행」을 누르면 _part01.mp4 같은 이름으로 각 구간이 저장됩니다.
결과가 0개라면 민감도를 0.2 정도로 낮춰 보세요. 반대로 너무 잘게 나뉘면 0.4 이상으로 올립니다.

② 수동 편집 (구간 직접 지정)

영상을 재생하면서 남기거나 지울 구간을 직접 지정합니다. 「✂ 수동 편집」탭에서 작업합니다.

구간 지정 방법

  1. 영상을 재생하다가 시작할 위치에서 멈추고 「구간 시작 [I]」를 누릅니다(I 키도 가능).
  2. 끝낼 위치로 이동해 「구간 끝 [O]」를 누릅니다(O 키도 가능).
  3. 「구간 추가」를 누르면 타임라인에 파란색 막대로 표시되고 목록에 추가됩니다.
  4. 여러 구간은 1~3을 반복합니다. 목록의 「삭제」버튼으로 개별 삭제할 수 있습니다.

이동(시크) 요령

  • 타임라인 바를 클릭하면 해당 비율의 위치로 점프합니다.
  • 「⏪ 10초 전」「10초 후 ⏩」로 미세 조정할 수 있습니다.
  • 시작과 끝을 반대로 지정해도 자동으로 정렬됩니다.
  • 0.1초 미만의 구간은 너무 짧아 추가할 수 없습니다.

처리 방식 선택

방식동작적합한 경우
✂ 선택 구간 잘라내기(삭제)지정 구간을 제거하고 나머지를 이어붙여 1개 영상으로 만듭니다.광고나 불필요한 장면을 제거할 때
🔗 선택 구간만 남기기지정 구간만 이어붙여 1개 영상으로 만듭니다.하이라이트 모음을 만들 때
📤 선택 구간만 파일로 추출구간마다 별도 파일로 저장합니다.장면별로 파일을 나눌 때

방식을 고르고 「선택 처리 실행」을 누르면 확인창이 뜹니다. 진행 상황은 공통 진행 바에서 확인할 수 있습니다.

③ 동시 편집 (2개 영상)

두 영상을 나란히 띄워 각각 다른 구간을 지정하고 같은 작업을 한 번에 적용합니다. 「🔀 동시 편집」탭에서 작업합니다.

  1. 「영상 A」「영상 B」에 파일을 선택하고 「🎬 둘 다 열기」를 누릅니다(개별로 열 수도 있습니다).
  2. 각 영상의 이동 버튼으로 위치를 맞추고 「A 시작 / A 끝」「B 시작 / B 끝」을 눌러 구간을 정합니다.
  3. 「구간 추가」를 누르면 A와 B 구간이 한 쌍으로 목록에 추가됩니다. B를 지정하지 않으면 A만 추가됩니다.
  4. 「🎬 동시 플레이」로 두 영상을 함께 확인하고 「⏸ 동시 정지」로 멈춥니다.
  5. 처리 방식을 고르고 「동일 구간 처리 실행」을 누르면 A → B 순서로 처리됩니다.

음성 → 텍스트 변환 (Whisper)

일본어 음성을 Whisper(base)로 텍스트로 바꿉니다. 동영상을 열면 「음성 → 텍스트 변환」카드가 표시됩니다.

  1. 「🎙 음성 → 텍스트 변환」을 누릅니다.
  2. 변환이 끝나면 타임스탬프가 붙은 텍스트가 표시됩니다.
  3. 「📋 복사」로 클립보드에 복사할 수 있습니다.
처음 실행 시 Whisper 모델 다운로드에 시간이 걸릴 수 있습니다. 영상이 길수록 처리 시간도 늘어납니다.

AI 편집 어시스턴트 (자연어 명령)

CLI(명령줄) 사용법

브라우저를 쓰지 않고 명령만으로 자동 분할할 수도 있습니다.

# 기본: 장면 전환을 감지해 분할
python scene_split.py video.mp4

# 분할 계획만 확인(실제 파일은 만들지 않음)
python scene_split.py video.mp4 --dry-run

# 민감하게 감지 / 출력 지정 / 출력 언어 변경
python scene_split.py video.mp4 -t 0.2 -o parts --lang ko

# 길이 범위 지정 / 재인코딩 없이 빠르게 자르기
python scene_split.py video.mp4 --min-duration 5 --max-duration 600
python scene_split.py video.mp4 --copy

input필수분할할 동영상 파일
-o, --out<이름>_split출력 폴더
-t, --threshold0.3전환 감지 민감도 (0.0~1.0)
--min-duration1.0구간 최소 길이(초)
--max-duration없음구간 최대 길이(초)

Before you start

movieXTrim detects scene changes in a video and splits it into multiple files, or lets you trim a video by choosing exactly which segments to keep or remove in your browser. Everything runs locally on your computer.

This guide walks through the on-screen controls, the CLI (command line), and what to do when something does not work. Use the language buttons in the top-right to switch to 日本語 / 한국어.

Requirements: Python 3.8+ / Flask / ffmpeg & ffprobe on PATH. Ollama and Whisper are also needed for the AI features.

STEPQuick start

  1. Run python webapp/app.py.
  2. Open http://localhost:5000 in your browser.
  3. Choose a file under "Open video" and press "Open". Once uploaded, the player and editing panels appear.
  4. Use the "Auto Split" or "Manual Edit" tab to start editing.

Pressing 📖 User Guide in the header opens this guide in a new tab, so you can read it side by side with the editor.

① Auto Split (scene change detection)

Automatically finds points where the colour or composition changes significantly and splits the file there. Useful for cutting a long recording into pieces in one go.

How to use it

  1. Set the sensitivity (threshold). Default is 0.30; lower values produce finer cuts, higher values detect only obvious changes.
  2. Set min / max duration. "Min" prevents very short fragments; "Max" evenly splits segments longer than the given number of seconds. Leave max empty for no limit.
  3. Press "Detect scene changes". The number of results appears and the dropdown is filled.
  4. Pick a point from the dropdown and press "Go to selected point" to seek there.
  5. Press "Run auto split". Segments are saved with names like _part01.mp4.
If nothing is detected, lower the threshold to around 0.2. If it splits too finely, raise it to 0.4 or more.

② Manual Edit (set segments yourself)

Choose the exact segments while watching the video. Use the "✂ Manual Edit" tab.

Marking a segment

  1. Play the video, pause where the segment should start, and press "Segment start [I]" (or the I key).
  2. Move to the end position and press "Segment end [O]" (or the O key).
  3. Press "Add segment". It appears as a blue bar on the timeline and in the list.
  4. Repeat steps 1-3 for more segments. Use "Delete" in the list to remove one.

Seeking tips

  • Click the timeline bar to jump to that position.
  • Use "⏪ Back 10s" and "Forward 10s ⏩" for fine adjustments.
  • Start and end are swapped automatically if entered in reverse.
  • Segments shorter than 0.1 seconds cannot be added.

③ Dual Edit (two videos)

Open two videos side by side, mark a different range on each, and apply the same operation to both. Use the "🔀 Dual Edit" tab.

  1. Choose files for "Video A" and "Video B" and press "🎬 Open both" (or open them individually).
  2. Use the seek buttons on each player, then press "A start / A end" and "B start / B end".
  3. Press "Add segment" to add the A/B pair to the list. If B is not set, only A is added.
  4. Press "🎬 Play together" to check both, and "⏸ Stop both" to pause.
  5. Choose a mode and press "Apply to both videos"; processing runs A then B.

Speech to text (Whisper)

Transcribes Japanese audio with Whisper (base). The "Speech → Text" card appears once a video is open.

  1. Press "🎙 Speech → Text".
  2. When it finishes, timestamped text is shown.
  3. Press "📋 Copy" to copy it to the clipboard.
The first run may take time while the Whisper model is downloaded. Longer videos take longer to process.

AI features (beta)

Check "🤖 Use AI features" in the "✂ Manual Edit" tab to enable AI controls. With it off, only regular editing is available.

Analyze key segments

Press "Analyze key segments with AI (beta)" to estimate the start and end of the important part from the transcript. Press "Apply AI suggestion" to put that range into the segment list.

AI editing assistant (natural language)

Type a command in plain English (or Japanese/Korean) and the AI interprets the segment and runs the edit.

  • keep only 5s to 15s
  • cut from 3s to 10s
  • extract 20s to 30s as a file
AI features need a local Ollama server with the gemma4:e2b model. Responses may take a while.

Results and downloads

When processing finishes, "Results" appears at the bottom of the page.

  • Download — save the file.
  • Preview — play it in a separate view (close with the button or Esc).

Files are also stored under web_results/<video-id>/.

Using the CLI

You can also split videos from the command line without opening a browser.

# Basic: detect scene changes and split
python scene_split.py video.mp4

# Preview the plan only (no files created)
python scene_split.py video.mp4 --dry-run

# Finer detection / output folder / output language
python scene_split.py video.mp4 -t 0.2 -o parts --lang en

# Set duration limits / cut without re-encoding
python scene_split.py video.mp4 --min-duration 5 --max-duration 600
python scene_split.py video.mp4 --copy
